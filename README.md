# やりくり（来月の支出を予測するアプリ）

給料日（初期設定: 25日）から次の給料日前日までを1サイクルとして、
**次のサイクルの支出を予測**し、変動費に使える額と「銀行に入金する額」を決めるための iPhone 向け PWA。
日々の細かい支出の管理はマネーフォワードに任せ、このアプリは「予測」と「予測の答え合わせ」に絞っています。

## 使い方

1. **予測タブ**（給料日の前後に）: 収入 − 固定費・単発の支出 ＝ 変動費に使える額 → 食費・日用品・交際費・医療費・美容室ごとに予測を入力 → 支出の合計と「銀行に入金する額」を確認。過去の実績（前回・直近平均・最大）が目安として出ます。給料日まで7日以内なら次のサイクルが最初に開きます
2. **実績タブ**（サイクルが終わったら）: マネーフォワードのカテゴリ別の合計を転記。予測との差と、直近サイクルの当たり具合（平均のずれ）が出ます。交際費の予定など日付が分かるものは「予定」として登録できます
3. **今月タブ**: 日付つきの記録・予定から、予算に対する残りを確認
4. **設定タブ**: 給料日、固定費（カード・家賃・NISA等）、カテゴリの編集、JSONバックアップ

データは端末の localStorage にのみ保存されます（外部送信なし）。

## 開発

ビルド不要の静的サイト。`serve.ps1 -Port 5174` でローカル確認できます。
アイコンは `generate-icons.ps1` で生成（PowerShell 5.1 のためコメントは ASCII のみ）。

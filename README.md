# やりくり（給料日サイクルの収支管理アプリ）

給料日（初期設定: 25日）から次の給料日前日までを1サイクルとして、
固定費を引いた「変動費に使える額」を見積もり、デビットカードの引き算式でやりくりするための iPhone 向け PWA。

## 使い方

1. **計画タブ**（給料日に）: 収入 − 固定費・単発の支出 = 変動費に使える額 → 食費・日用品・交際費・医療費・美容室に配分 → 「銀行に入金する額」を確認
2. **記録タブ / ホーム**: デビットカードで使うたびに記録。予定（例: 22日に交際費8,000円）も先に入れておくと残額から差し引いて表示
3. **ホーム**: 残りの使えるお金、1日あたりの目安、カテゴリ別の残り
4. **設定タブ**: 給料日、固定費（カード・家賃・NISA等）、カテゴリの編集、JSONバックアップ

データは端末の localStorage にのみ保存されます（外部送信なし）。

## 開発

ビルド不要の静的サイト。`serve.ps1 -Port 5174` でローカル確認できます。
アイコンは `generate-icons.ps1` で生成（PowerShell 5.1 のためコメントは ASCII のみ）。
